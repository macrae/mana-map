The ranking answers the two structural holes: renewable bodies for Yawgmoth, whose ability eats a creature per activation, and a second kill that does not run through Blowfly Infestation plus Nest of Scarabs.

    Blowfly Infestation + Nest of Scarabs: unbounded, and does it need the drain?

    TODO This section is awaiting content.

    The question
    Resolve the stack and then the resulting loop. (a) Is the loop unbounded, and what exactly sustains it — name the object that dies each iteration and why Blowfly Infestation's intervening-if condition is met every time? State how many completed iterations are required to reduce all four opponents from 40 to 0, and what ends the loop. (b) If Zulaport Cutthroat were NOT on the battlefield and no other life-loss effect existed, would this be a mandatory loop with no way to stop it, and does that make the game a draw under CR 104.4b?

    Result. REFUTED AS A KILL ON THIS BOARD. The Blowfly Infestation + Nest of Scarabs engine is genuinely unbounded - the object that dies each iteration is the Insect token Blowfly just targeted, and the -1/-1 counter Blowfly placed is still on it when it dies, so the intervening-'if' is satisfied on both the look-back check and the resolution check every time. But the engine is drainless here. State-based actions kill the counter-bearing token BEFORE Nest of Scarabs' trigger resolves, so at the instant Blowfly's first trigger is put on the stack the only creature on the battlefield is Zulaport Cutthroat; Blowfly says 'target creature' and is mandatory, a legal target exists, so Zulaport must be targeted and dies on iteration one. Total drain: exactly 3 per opponent (Fume Spitter, Insect token X, Zulaport itself). Opponents end at 37, not 0; no finite number of iterations gets them to 0. The deficiency is one body: the loop needs the drain creature plus TWO other creatures on the battlefield when it starts, at which point Blowfly always has a spare token to eat and the drainer is never the forced target - 38 completed iterations then take four opponents from 40 to 0. Nothing external ends the loop; the controller ends it by ordering Blowfly's trigger above Nest of Scarabs', which empties the battlefield of creatures so Blowfly's next trigger has no legal target and is removed from the stack. Because that choice is available every iteration, CR 104.4b does not apply and the drainless version is not a draw.

    Case A-001 Blowfly Infestation + Nest of Scarabs: unbounded, and does it need the drain?
    Rules version June 19, 2026 · status: cleared in 3 review cycle(s) · tap to open     Verified
    1. Resolve the top object of the stack (pos 1): Zulaport Cutthroat's death trigger from Fume Spitter having been sacrificed to pay the activation cost.
      Each opponent loses 1 life and you gain 1 life. Opponents A-D: 40 -> 39 each. You: 40 -> 41. This is drain #1. Nothing else changes; Blowfly Infestation did NOT trigger on Fume Spitter's death, because Fume Spitter had no -1/-1 counter on it and Blowfly's intervening-'if' condition was false when the trigger event occurred.
      CR 405.5 — “When all players pass in succession, the top (last-added) spell or ability on the stack resolves.”
    2. Resolve pos 0: Fume Spitter's activated ability, 'Put a -1/-1 counter on target creature,' targeting Insect token X.
      YOU are the ability's controller, so YOU put the -1/-1 counter on Insect token X. Two consequences fire at once: (i) Insect token X, a 1/1, now has a -1/-1 counter and is 0/0; (ii) Nest of Scarabs' ability ('Whenever you put one or more -1/-1 counters on a creature, create that many 1/1 black Insect creature tokens') triggers. It has triggered but is not yet on the stack and has done nothing yet.
      CR 608.2c — “The controller of the spell or ability follows its instructions in the order written.”
      CR 122.1a — “A +X/+Y counter on a creature or on a creature card in a zone other than the battlefield, where X and Y are numbers, adds X to that object’s power and Y to that object’s toughness. Similarly, -X/-Y counters subtract from power and toughness.”
      CR 603.2 — “Whenever a game event or game state matches a triggered ability’s trigger event, that ability automatically triggers. The ability doesn’t do anything at this point.”
    3. The stack is now empty and a player would receive priority, so state-based actions are performed FIRST, before any waiting trigger is put on the stack.
      Insect token X has toughness 0, so it is put into its owner's graveyard - it dies. On the repeated SBA check the token, now in a zone other than the battlefield, ceases to exist. Critically, Nest of Scarabs' waiting trigger has NOT resolved; no new token exists yet. Battlefield creatures after this step: Zulaport Cutthroat, and nothing else.
      CR 117.5 — “Each time a player would get priority, the game first performs all applicable state-based actions as a single event (see rule 704, “State-Based Actions”), then repeats this process until no state-based actions are performed. Then triggered abilities are put on the stack (see rule 603, “Handling Triggered Abilities”).”
      CR 704.5f — “If a creature has toughness 0 or less, it’s put into its owner’s graveyard.”
      CR 700.4 — “The term dies means “is put into a graveyard from the battlefield.””
      CR 704.5d — “If a token is in a zone other than the battlefield, it ceases to exist.”
    4. Determine which abilities trigger on Insect token X's death, and test Blowfly Infestation's intervening-'if' condition.
      Blowfly Infestation reads 'Whenever a creature dies, if it had a -1/-1 counter on it, put a -1/-1 counter on target creature.' 'Whenever a creature dies' is a leaves-the-battlefield ability, so the game looks back in time and uses the appearance of Insect token X immediately prior to the event - at which point it carried the -1/-1 counter placed in step 2. The intervening-'if' condition is therefore TRUE and Blowfly triggers. Zulaport Cutthroat also triggers ('or another creature you control dies'). Pending triggers: Nest of Scarabs (from step 2), Blowfly Infestation, Zulaport Cutthroat.
      CR 603.10 — “However, some triggered abilities are exceptions to this rule; the game “looks back in time” to determine if those abilities trigger, using the existence of those abilities and the appearance of objects immediately prior to the event.”
      CR 603.10a — “Some zone-change triggers look back in time. These are leaves-the-battlefield abilities, abilities that trigger when a player sacrifices a permanent, abilities that trigger when a card leaves a graveyard, and abilities that trigger when an object that all players can see is put into a hand or library.”
      CR 603.6c — “Leaves-the-battlefield abilities trigger when a permanent moves from the battlefield to another zone, or when a phased-in permanent leaves the game because its owner leaves the game.”
      CR 603.4 — “When the trigger event occurs, the ability checks whether the stated condition is true. The ability triggers only if it is; otherwise it does nothing.”
    5. THE PIVOT. All three waiting triggers are put on the stack in one batch, before any player receives priority. Blowfly Infestation's target must be chosen NOW, as it is put on the stack.
      You control all three triggers and may order them freely, but ordering cannot help: no ability resolves until the whole batch is on the stack, so Nest of Scarabs' token does not exist when Blowfly's target is locked in. The only creature on the battlefield is ZULAPORT CUTTHROAT. Blowfly says 'target creature', not 'up to one target creature' (contrast your commander Yawgmoth, which does say 'up to one'), so it does not permit zero targets and you must announce a legal target when one exists; the ability is removed from the stack only if NO legal choice can be made. A legal choice can be made - Zulaport Cutthroat - so Blowfly's trigger goes on the stack targeting your own drain creature. You cannot decline.
      CR 603.3b — “First, each player, in APNAP order, puts each triggered ability they control with a trigger condition that isn’t another ability triggering on the stack in any order they choose.”
      CR 115.1d — “The target(s) are chosen as the ability is put on the stack; see rule 603.3d.”
      CR 601.2c — “The player announces their choice of an appropriate object or player for each target the spell requires.”
      CR 115.6 — “A spell or ability that requires targets may allow zero targets to be chosen.”
      CR 603.3d — “If a choice is required when the triggered ability goes on the stack but no legal choices can be made for it, or if a rule or a continuous effect otherwise makes the ability illegal, the ability is simply removed from the stack.”
    6. Resolve the batch in the best available order for you: Blowfly placed on the stack first (bottom), then Zulaport's drain, then Nest of Scarabs on top, so Nest resolves first.
      Nest of Scarabs resolves: create one 1/1 black Insect token, call it Y. Board creatures: Zulaport Cutthroat, Insect Y. Zulaport's trigger resolves: drain #2 - opponents 39 -> 38 each, you 41 -> 42. Blowfly Infestation resolves: its intervening-'if' is re-checked and is still true (Insect token X's having had a -1/-1 counter is a completed past fact that cannot become false), so it resolves and YOU put a -1/-1 counter on Zulaport Cutthroat. Zulaport is now 0/0, and Nest of Scarabs triggers again because you put that counter.
      CR 608.2a — “If a triggered ability has an intervening “if” clause, it checks whether the clause’s condition is true. If it isn’t, the ability is removed from the stack and does nothing. Otherwise, it continues to resolve.”
      CR 608.2c — “The controller of the spell or ability follows its instructions in the order written.”
    7. State-based actions: Zulaport Cutthroat has toughness 0 and is put into your graveyard. Determine what triggers.
      Zulaport's own ability sees its own death ('Whenever this creature or another creature you control dies') and triggers - drain #3, resolving to opponents 38 -> 37 each, you 42 -> 43. Blowfly triggers again: looking back in time, Zulaport had a -1/-1 counter on it, so the condition holds. Blowfly's new trigger is put on the stack and the only creature on the battlefield is Insect token Y, so it targets Y. THE DRAIN IS NOW OVER: Zulaport Cutthroat is in the graveyard, no Blood Artist / Bastion of Remembrance effect is on the battlefield in this scenario, and every subsequent death produces no life loss.
      CR 704.5f — “If a creature has toughness 0 or less, it’s put into its owner’s graveyard.”
      CR 603.10a — “Some zone-change triggers look back in time. These are leaves-the-battlefield abilities, abilities that trigger when a player sacrifices a permanent, abilities that trigger when a card leaves a graveyard, and abilities that trigger when an object that all players can see is put into a hand or library.”
    8. Characterize the steady-state loop that now runs (Blowfly Infestation + Nest of Scarabs + Insect tokens only), and prove the intervening-'if' is satisfied on every iteration.
      Invariant at the start of each iteration: exactly two 1/1 Insect tokens A and B on the battlefield, and one Blowfly trigger on the stack targeting A. (1) Blowfly resolves; you put a -1/-1 counter on A; A becomes 0/0 and Nest of Scarabs triggers. (2) SBA: A dies. The object that dies EVERY iteration is the Insect token Blowfly just targeted, and the counter Blowfly placed is still on it - nothing in this loop removes counters and no +1/+1 counter is ever present to annihilate it - so 'if it had a -1/-1 counter on it' is true on the look-back check and true again on resolution. (3) Blowfly re-triggers; the Nest token from (1) does not exist yet, so the only creature is B, and Blowfly targets B - a legal target always exists, so the trigger is never removed. (4) You place Blowfly's trigger on the stack first and Nest's on top; Nest resolves, creating token C. Board is now {B, C} with a Blowfly trigger targeting B: the invariant, re-established. The loop is therefore unbounded - it can be repeated arbitrarily many times, consumes no mana, touches no library, and its net creature count never changes.
      CR 603.4 — “If the ability triggers, it checks the stated condition again as it resolves. If the condition isn’t true at that time, the ability is removed from the stack and does nothing.”
      CR 122.1a — “A +X/+Y counter on a creature or on a creature card in a zone other than the battlefield, where X and Y are numbers, adds X to that object’s power and Y to that object’s toughness. Similarly, -X/-Y counters subtract from power and toughness.”
      CR 603.3b — “First, each player, in APNAP order, puts each triggered ability they control with a trigger condition that isn’t another ability triggering on the stack in any order they choose.”
    9. ANSWER (a), part 1: how many completed iterations take all four opponents from 40 to 0?
      NONE. No finite number exists, and the line as a win condition on THIS board is refuted. The loop is unbounded but it is DRAINLESS: Zulaport Cutthroat is killed by Blowfly Infestation on the very first loop iteration, because at the instant Blowfly's first trigger is placed (step 5) Zulaport is the only creature on the battlefield and Blowfly's mandatory target must be chosen then. Total life loss dealt is exactly 3 per opponent (Fume Spitter's death, Insect token X's death, Zulaport's own death); opponents finish at 37, not 0, and no ordering of the triggers can do better than 3, since the alternative order kills Zulaport with zero creatures left and ends the loop one iteration sooner. THE FIX, stated precisely: the loop needs the battlefield to hold the drain creature plus TWO other creatures when it starts (this board has the drainer plus one). With one additional creature, Blowfly always has a spare token to target and the drainer is never the only legal target; each iteration then kills exactly one creature and fires Zulaport once. Forty deaths are required to take an opponent from 40 to 0; Fume Spitter and Insect token X supply the first two, so 38 COMPLETED LOOP ITERATIONS finish it, and all four opponents reach 0 simultaneously and lose as a state-based action.
      CR 704.5a — “If a player has 0 or less life, that player loses the game.”
    10. ANSWER (a), part 2: what ends the loop?
      Nothing external ends it - no mana is spent, no card is drawn, no life is lost, and the token count is conserved. The loop ends only by YOUR choice, and the choice is the ordering of the two simultaneous triggers you control each iteration. Put Blowfly's trigger ON TOP of Nest of Scarabs' trigger instead of underneath it: Blowfly then resolves first, kills the last remaining Insect token, and at the moment its next trigger would be put on the stack there are ZERO creatures on the battlefield, so no legal choice can be made for its target and the trigger is simply removed from the stack. The two outstanding Nest triggers then resolve into two fresh Insect tokens and the game continues normally. This exit is available on every single iteration.
      CR 603.3b — “First, each player, in APNAP order, puts each triggered ability they control with a trigger condition that isn’t another ability triggering on the stack in any order they choose.”
      CR 603.3d — “If a choice is required when the triggered ability goes on the stack but no legal choices can be made for it, or if a rule or a continuous effect otherwise makes the ability illegal, the ability is simply removed from the stack.”
    11. ANSWER (b), literal reading: delete Zulaport Cutthroat from the board, change nothing else, and run the same stack.
      The loop never starts. Fume Spitter's ability resolves and puts a -1/-1 counter on Insect token X; Nest of Scarabs triggers; SBA puts the 0/0 token into the graveyard. Blowfly Infestation triggers with its condition satisfied - but the battlefield now contains NO creatures at all (Zulaport is absent and Nest's token has not been created yet), so no legal target can be chosen and the trigger is removed from the stack. Nest's trigger then resolves for one Insect token and the game moves on. Exactly one -1/-1 counter was placed and exactly one token was made. There is no loop, so CR 104.4b is not reached.
      CR 704.5f — “If a creature has toughness 0 or less, it’s put into its owner’s graveyard.”
      CR 603.3d — “If a choice is required when the triggered ability goes on the stack but no legal choices can be made for it, or if a rule or a continuous effect otherwise makes the ability illegal, the ability is simply removed from the stack.”
    12. ANSWER (b), general reading: a Blowfly + Nest loop already running with no life-loss effect (which is exactly the state this board reaches after step 7). Is it a mandatory loop, and does CR 104.4b make the game a draw?
      NO on both counts. CR 104.4b requires a loop of mandatory actions 'repeating a sequence of events with no way to stop', and its own second sentence exempts loops containing an optional action; CR 732.4 draws only a loop that 'contains only mandatory actions'. This loop does not qualify. Blowfly's effect is mandatory and its target is forced whenever only one creature is available, but the loop also contains a free game choice its controller makes every iteration: the relative order in which the simultaneous Blowfly and Nest of Scarabs triggers are placed on the stack. One of the two available orders sustains the loop and the other terminates it (step 10). CR 732.5's protection - that no player can be forced to take a loop-breaking action outside the loop - does not rescue the draw claim here, because the terminating choice is made entirely among objects involved in the loop itself, not by sacrificing some unrelated permanent. Verdict: there IS a way to stop, so the antecedent of 104.4b fails and the game is NOT a draw. The controller is obliged to make the choice that ends it rather than shortcut an infinite repetition. Practically: without a life-loss effect the loop accomplishes nothing but a pile of Insect tokens, and you should end it deliberately.
      CR 104.4b — “If a game that’s not using the limited range of influence option (including a two-player game) somehow enters a “loop” of mandatory actions, repeating a sequence of events with no way to stop, the game is a draw. Loops that contain an optional action don’t result in a draw.”
      CR 732.4 — “If a loop contains only mandatory actions, the game is a draw.”
      CR 732.5 — “No player can be forced to perform an action that would end a loop other than actions called for by objects involved in the loop.”
